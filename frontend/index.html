    What this prototype actually does

    Real components: live soil-moisture / precipitation telemetry from Open-Meteo's public weather API for the entered coordinates, and a genuine acoustic-feature speech-emotion classifier (MFCCs, pitch, energy) trainable on the open RAVDESS dataset.

    Simulated component: the final "risk score" and lending decision are produced by a small, fully disclosed rule set built for this hackathon prototype — not a model trained on real repayment outcomes. Every assessment ships with a written explanation of exactly how its number was produced.

    What we're explicit about with the jury: using speech emotion as a proxy for repayment intent is a proposed, unproven hypothesis, not an established underwriting signal. Presenting it otherwise would be misleading. The honest framing is: "worth piloting and validating," not "solved."
